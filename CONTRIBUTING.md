# Contributing

Contributions are welcome!

1. Fork → create a branch → commit (Conventional Commits) → open a PR.
2. Report bugs and request features via [Issues](https://github.com/helbertparanhos/vercel-mcp-pro/issues).
3. For tools, follow the existing pattern: one `defineTool` per operation, a Zod
   schema with `.describe()` on every field, and `write: true` on any mutation.
4. Run `npm run build` and confirm `tsc` is clean before opening the PR.

Contact: contato@helbertparanhos.com.br
